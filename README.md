## 🎯 The Philosophy: Dopamine Antidote

Traditional social feeds are weaponized dopamine machines designed to keep your eyes locked to an infinite stream of algorithmic outrage. **Void** is the exact opposite — a tranquil sanctuary designed to satisfy the reflex of opening an app while gently guiding you back to reality.

| ⚡ The Dopamine Trap (Traditional Apps) | 🌿 The Mindful Alternative (**Void**) |
| :--- | :--- |
| **Algorithmic Outrage:** Engineered to provoke reaction | **Calm Reflections:** Curated prompts for personal introspection |
| **Infinite Content Trap:** Endless novelty feeding addiction | **The Infinite Void:** Procedural nothingness to exhaust the scroll reflex |
| **Loud Video Auto-Plays:** Sensory overload & spikes | **Void Reels:** Ambient vertical moments with soft pacing |
| **Notification Anxiety:** Red badges and phantom buzzes | **Quiet Monotasking:** Built-in Pomodoro focus timers & nudges |
| **Data Mining & Trackers:** Pervasive surveillance | **100% Client-Side:** Zero cookies, zero telemetry, zero analytics |

## ✨ Core Features

### 🌌 1. The Infinite Void (The Procrastination Buster)
A unique digital detox experience. When you find yourself reflexively opening a tab to procrastinate, enter **The Infinite Void**. 
- Scroll endlessly through vast, procedurally generated cosmic nothingness.
- Deep depth tracking counters that show you how far you searched for dopamine without finding traps.
- Gentle, humorous nudge to close the tab and return to work.

### 🌿 2. Mindful Reflections Feed
- Low-stimulation thought stream featuring intentional quotes, grounding mantras, and quiet community insights.
- Distraction-free interactions: gentle reactions without toxic comment sections.

### 🎬 3. Void Reels
- Clean, vertical video experience designed around ambient visual aesthetics.
- Instagram-style smooth heart bursts on double-tap.
- Quiet comment drawer that opens without breaking media flow.

### ⏱️ 4. Focus & Pomodoro Work Intervention
- Built-in 25-minute focus session timer.
- Automatic mindfulness intervention if scrolling patterns indicate distraction.
- Single-click action to switch back to productive deep work.

### 💬 5. Distraction-Free Direct Messages
- Simulated, peaceful messaging experience.
- Soft typing indicators, calm cadence, and no urgent ping badges.

### 🌗 6. Adaptive Atmosphere
- **Dusk Dark Mode:** Deep cosmic obsidian (`#090d16`) engineered for late-night calm and eye comfort.
- **Paper Light Mode:** Clean, warm editorial aesthetic inspired by physical paper journals.

## ⌨️ Keyboard Shortcuts

Void is designed for effortless, fluid navigation with physical keyboard controls:

| Key | Action |
| :---: | :--- |
| <kbd>Esc</kbd> | Dismiss any active modal, story viewer, or comment drawer |
| <kbd>↓</kbd> / <kbd>↑</kbd> | Smoothly snap to the next / previous reel |
| <kbd>Space</kbd> | Play or pause active ambient media |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Focus the universal mindful search bar |

## 🛠️ Architecture & Specs

Void is intentionally crafted with **zero external frameworks** to demonstrate the speed, beauty, and resilience of the modern native web:

```
void-dusk/
├── index.html       # Complete application (Semantic HTML5, CSS Variables, Modular Vanilla JS)
├── README.md        # Documentation & Project Showcase
├── LICENSE          # Open Source MIT License
└── .github/         # Automated GitHub Actions deployment pipeline
```

* **Zero Dependencies:** No React, no Vue, no Tailwind, no NPM packages.
* **Instant Load:** Blazing-fast static delivery with zero hydration lag.
* **Responsive Design:** Optimized across 4K displays, ultrawide monitors, tablets, and mobile screens.
* **Accessibility:** Semantic HTML structure with full keyboard focus management.

## 💻 Run Locally

Running Void on your local machine requires no build steps or dependencies:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rasteq/void-dusk.git
   ```

2. **Open the project:**
   Simply double-click `index.html` to launch it instantly in any browser.

   *(Optional) If using VS Code, click **"Go Live"** with Live Server or run:*
   ```bash
   npx serve .
   ```
