## 📖 Overview

**void** is an authentic, responsive social web experience built from scratch. It blends the engaging UI patterns of modern social networks (Instagram, Threads, and Facebook) with an intentional **Infinite Void (Digital Detox)** feature designed to break addictive scrolling loops through mindful box-breathing exercises.

---

## ✨ Key Features

- 📱 **Authentic Social Feed**: Seamless post feed featuring rich media cards, inline comments, interactive polls, and options menus.
- 🎬 **Full-Screen Reels Player**: TikTok & Instagram-style snap-scroll vertical video stream with tactile interactions.
- ⭕ **Interactive Stories Tray**: Circular gradient story rings with an integrated full-screen story viewer and progress bar.
- 🧘 **The Infinite Void (Digital Detox)**: Anti-doomscrolling mode featuring box-breathing animations and mindful prompts.
- 🌓 **Curated Dark & Light Modes**: 
  - *Nocturne Velvet* (Dark mode for night immersion)
  - *Editorial Gallery* (Clean, tactile light mode)
- ❤️ **Engaging Micro-Interactions**: Double-tap heart burst animation, like counters, bookmarks, and animated toasts.
- 📲 **100% Mobile & Desktop Responsive**: Sticky desktop navigation sidebars and a native-feeling mobile app bar.

---

## 🛠️ Built With

* **HTML5** — Clean semantic structure and layout architecture.
* **CSS3** — Custom properties (design tokens), flexbox, grid, glassmorphism, and smooth keyframe animations.
* **Vanilla JavaScript** — High-performance DOM manipulation with zero dependencies or external libraries.

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone this repository:**
   ```bash
   git clone https://github.com/rasteq/void.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd void
   ```

3. **Launch the project:**
   Simply double-click `index.html` or open it with the **Live Server** extension in VS Code.
