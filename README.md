### About

Traditional feeds are engineered to exploit your attention through endless outrage, red notification dots, and engagement bait. 

**Void** is the opposite — a tranquil, low-stimulation environment designed to satisfy the subconscious reflex of checking a feed while gently guiding your focus back to what actually matters.

### Features

* **The Infinite Void** — Procedural endless scrolling with zero dopamine rewards, designed to break doomscrolling habits.
* **Mindful Feed** — Calm, reflective thought stream with quiet interactions and zero toxic comment threads.
* **Void Reels** — Peaceful vertical moments with ambient pacing, gesture navigation, and double-tap to like.
* **Focus Mode** — Built-in 25-minute Pomodoro timer with mindful interventions when distraction is detected.
* **Quiet Messenger** — Low-cadence, simulated direct messaging with soft typing indicators and no notification spam.
* **Adaptive Atmosphere** — Handcrafted **Dusk Dark** and **Paper Light** themes designed for eye comfort.

### Run Locally

Void is built with 100% pure HTML, CSS, and modern JavaScript. There are zero dependencies and no build steps:

```bash
git clone https://github.com/rasteq/void-dusk.git
```

Double-click `index.html` to open it immediately in any web browser.

### Keyboard Shortcuts

* `Esc` — Close any open modal, story, or drawer
* `↑` / `↓` — Move to previous / next reel
* `Space` — Play / pause ambient reels
* `Ctrl` + `K` — Focus search bar
