### ✨ Core Philosophy & Features

* 🌿 **Mindful Home Feed:** Low-stimulation reflections, thought prompts, and monotasking nudges instead of engagement-bait algorithms.
* 🌌 **The Infinite Void:** A procedural detox stream designed to scroll infinitely without content, helping break doomscrolling impulses and redirect focus back to meaningful work.
* 🎬 **Void Reels:** Ambient, peaceful vertical moments and micro-reflections with gesture navigation and double-tap interactions.
* ⏱️ **Focus & Work Mode:** Built-in Pomodoro focus sessions and gentle interventions when excessive scrolling is detected.
* 💬 **Distraction-Free Messenger:** Simple, private simulated direct messaging with calming typing indicators and zero notification spam.
* 🌗 **Adaptive Themes:** Deep Void Dark mode and Soft Paper Light mode, with full responsive layouts for desktop, tablet, and mobile.
* 🔒 **Local & Private:** 100% client-side with zero tracking, external telemetry, or ad pixels.

### 🚀 Running Locally

No build tools, Node dependencies, or installation required:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/rasteq/void-dusk.git
   ```
2. Open `index.html` directly in any modern web browser:
   * Double-click `index.html`, or
   * Use VS Code Live Server / any static HTTP server.

### ⌨️ Keyboard Shortcuts
* `Esc` — Close any active modal, story, or comment drawer
* `↓` / `↑` — Navigate between Void Reels
* `Space` — Pause / Resume ambient reels
